# 来源 4、5 接入、来源替换与稳定性验证

> 语言：简体中文。English mirror: [`../SOURCE_STABILITY.md`](../SOURCE_STABILITY.md)。

## 1. 已启用来源

JAI-021 在 JAI-011 的三个 Adapter 之上新增两个公开、只读的官方来源：

- `ncss-jobs` 使用 NCSS 官方公开职位页自身调用的 GET 列表接口，并读取公开详情；不执行登录、收藏、简历或投递动作。
- `shanghai-public-institution` 使用上海市人社局事业单位专栏，只接受 `/tzpgg_17408/` 招聘公告路径；排除拟聘公示与报名系统。
- `china-mobile-recruitment` 按 W6 稳定性闸门替换反复不可达的国资委来源。它只用 GET 读取官方公告页声明的同源静态 JSON 列表与详情 JSON；注册、登录、简历和投递动作仍全部排除。

目录仍保留 5 个 `active`、`enabled` 来源，均有显式运行时注册和离线 Adapter 契约测试。`sasac-recruitment` 保留为 `blocked` 且停用，并保留历史 Adapter/样本：其公开桌面 CDN 在 2026-08-26 与 2026-08-27 均不可达，官方移动入口又暴露过期 TLS 证书。新增固定样本全部为合成脱敏内容；线上页面不会进入提交。

## 2. 证据规则

NCSS 在实体化公开详情前保留官方岗位 ID、标题、单位、地区、学历、人数和发布时间。上海单位名称只从招聘标题中固定招聘公告后缀之前的精确文本确定，并保留该标题作为证据。中国移动保留公开公告 ID、页面显示的发布单位、标题、发布时间、可见正文与附件链接。只有图片的正文会保留经过同源校验的图片 URL 作为证据，但不下载、不做 OCR。JSON 的 `text5`/下线时间只作为来源元数据保留，绝不标注为报名截止；只有可见文字中的明确截止日期才能生成该字段。

日期抽取允许冒号或“为”连接词，也允许值出现在下一行。对于只有一个明确终点的“即日起”或“自公告发布之日起”范围，只输出有证据的截止日期，不构造开始日期。NCSS 缺失的截止时间以及江苏综合专题缺失的单位/截止时间继续保持为空。

## 3. 离线验收

NCSS、上海事业单位招聘和中国移动替代来源各有一份合成列表与三份合成详情样本。契约测试覆盖过滤、同源 URL 限制、游标、公开 GET 方法、元数据、显式失败和运行时注册。PostgreSQL 验收把九份文档写入两次：首次均为 `created`，第二次均为 `unchanged`，最终只保留九条版本 1 记录。

## 4. 每日观测命令与指标

执行一次不写数据库或文件的有界观测：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_source_stability.py --limit 3
```

命令把每站限制为 1～10 条详情，使用并发 1 及共享重试/限速策略，隔离详情失败，且只输出 JSON。指标为：

- 来源成功率：完全成功的来源运行数除以所选来源数；
- 详情成功率：成功读取的详情数除以尝试详情数；
- 重复率：成功详情中重复的规范 URL 或规范内容 SHA-256 指纹占比；
- 核心字段完整率：每条成功详情的单位、标题、地区、截止时间、来源链接五项有证据字段占比。

任何来源失败的观测都不是合格稳定日。成功但列表为空的来源保留为零条运行，不虚构完整率。
