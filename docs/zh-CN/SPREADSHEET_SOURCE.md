# 表格数据源契约

> English: [Spreadsheet source contract](../SPREADSHEET_SOURCE.md)

## 1. 目的与状态

本文定义 JAI-052 的设计闸门。项目负责人已批准一条增量加速轨：先把每日更新的 Excel 工作簿作为只读 Agent 的首个信息源。既有爬虫、调度、投递和前端成果全部保留，不被替换，也不因此视为已经完成。

当前尚未提供或检查工作簿。列名、工作表名、行身份、更新语义、访问方式和刷新频率均未知，不得猜测。

## 2. 数据源边界

实现必须明确区分三层：

1. **原始观测层**：记录来源 URL/工作簿身份、工作表身份、获取时间、可获得的 provider 更新时间元数据、内容哈希及不可变原始快照引用。原始业务文件和下载快照属于运行数据，不得提交到 Git。
2. **清洗记录层**：执行确定性的表头、空白、日期和值规范化、分类、校验和去重。以有界安全原因码和来源坐标保留拒收行；绝不编造缺失值。
3. **统一岗位层**：把接受的行映射到现有稳定岗位查询边界并保留来源证据。Agent 和页面读取这一层，不直接读取任意工作簿单元格。

爬虫继续作为统一岗位的另一类生产者。JAI-052 不得删除爬虫数据表、Adapter、调度历史或来源证据。

## 3. 身份、刷新与幂等

准确身份规则必须在工作簿审计后审批。设计至少需要区分：

- 工作簿与工作表身份；
- 来源行身份或有文档说明的确定性回退身份；
- 行内容哈希与规范化内容哈希；
- 首次/最近观测时间及来源提供的更新时间（如有）；
- 未变化、已变化、新增、当前快照缺失及拒收观测。

重复刷新同一工作簿版本不得产生重复统一记录。后续快照中消失的行不得被自动硬删除；必须由获批策略决定标记为停用、过期或仅“本次未观测”。来源快照和导入运行必须可审计发现、接受、变化、未变化、拒收和缺失数量。

## 4. 清洗与分类

JAI-052 只能实现由实际工作簿证据确认并经审批的规则。候选分类可以包括单位、单位类型、地区、岗位族、学历、经验、报名截止时间、来源 URL 和自由文本备注，但审计确认前都不是既定来源列。

规则必须确定、可测试。歧义值保持显式，原始单元格文本可追溯，分类规则变化必须增加版本。合成固定样本可以模拟获批结构；真实工作簿行、个人数据、凭据和下载文件不得进入测试或 Git。

## 5. 访问与安全

- JAI-052 只从只读访问开始。
- 公开链接只有在负责人提供并批准后才能登记为来源配置。私有链接、访问 Token、Cookie、密码和签名 URL 不得提交，也不得出现在日志、固定样本、数据库错误文本或文档中。
- 如果需要认证，必须在只读审计后另行审批访问机制和环境变量边界。不得绕过登录、验证码、访问控制、共享限制或 provider 条款。
- provider 错误映射为安全内部原因码；不持久化原始响应正文或密钥。

## 6. Agent 与页面边界

加速轨的首个切片保持只读：

1. JAI-052 建立表格获取/规范化契约和统一来源 Adapter。
2. JAI-032 在统一岗位上提供稳定搜索、详情、筛选和解释服务。
3. JAI-033 首个切片只暴露只读 Agent Tools。
4. JAI-034 实现单 Agent 编排与评测。
5. JAI-053 在既有 JAI-050 正式页面壳中增加 Agent 问答与筛选体验。

`run_crawl`、生成日报、来源启停、重跑、投递、写回工作簿及其他写操作均不属于本切片。只有恢复原依赖与审批闸门后才重新进入计划。

## 7. 审批闸门

| 闸门 | 证据 | 批准后权限 |
|---|---|---|
| G0 | 远端 JAI-027/JAI-050 分支与检查点标签已核验 | 保留调整前基线；不改变产品行为 |
| G1 | 负责人提供工作簿链接并授权只读检查；登记工作表/表头/更新证据 | 只读取并分析指定工作簿 |
| G2 | 负责人批准准确字段映射、身份、消失、刷新与访问规则 | 使用合成固定样本实现导入器 |
| G3 | 离线测试与 PostgreSQL 测试只操作名称以 `_test` 结尾的数据库；不写真实来源 | 实现有界持久化导入与统一映射 |
| G4 | 负责人在只读生产审计后批准每日刷新启用 | 启用与爬虫调度相互独立的计划刷新 |

G1 不授权数据库迁移、后台刷新、生产导入、外部写入或 Agent 实现。任何新迁移、认证连接器或真实周期获取都必须先提交影响证据再开放闸门。

## 8. G1 接入检查清单

负责人提供链接后，在不暴露密钥的前提下登记：

- provider 和链接类型、公开或需认证访问；
- 工作簿身份、工作表清单、表头行、合并单元格、公式及隐藏行列；
- 不含样本内容的结构类型、大致行数和更新标识；
- 行是追加、原地修改、删除、重排还是跨工作表拆分；
- 候选稳定键和重复情况；
- 日期/时区、空值/错误/公式语义及分类词表；
- provider 对自动只读访问的频率/导出限制及相关条款。

G1 报告必须分别列出已观察事实、未决问题和建议映射。只有 G2 获批后才开始实现。
