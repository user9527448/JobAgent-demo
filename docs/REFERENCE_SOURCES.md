# 非官方招聘信息参考源

本文档登记只用于人工交叉核验、市场补充或未来授权集成的非官方招聘平台。它与 [`config/source_catalog.toml`](../config/source_catalog.toml) 中可实现 Adapter 的采集目标严格分离；本文档中的来源不得因为“已登记”而进入自动采集。

## 使用原则

1. 官方招聘站、政府/公共就业服务站仍是岗位事实和投递入口的首要证据。
2. 非官方平台只补充岗位发现、薪资区间、岗位命名和企业活跃度线索；关键字段必须回到企业官方页或其他可追溯来源确认。
3. 不登录平台账号，不处理验证码，不模拟用户操作，不绕过反爬、访问控制或付费限制。
4. 平台条款禁止自动抓取时，只允许人工查看；除非以后取得书面授权或官方 API/数据许可，否则不开发 Adapter。
5. 不保存个人简历、聊天记录、招聘者身份、联系方式或其他个人数据。

## 未来授权接入条件

只有同时满足以下条件，才可把参考源转为机器可读集成：

- 平台提供官方 API、合作数据源或明确书面授权；
- 授权范围允许本项目的访问频率、保存字段和个人使用场景；
- 新建独立 Issue 和 Adapter，加入限速、审计、契约样本和删除/到期策略；
- 与官方来源冲突时保留双方证据，不用平台数据覆盖官方原文。
